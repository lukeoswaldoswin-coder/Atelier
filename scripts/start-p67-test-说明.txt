P6.7 测试版 —— 启动与实机检查说明
=====================================

一、怎么启动
------------

双击：scripts\start-p67-test.cmd

会出现一个黑窗口，显示 Electron 路径和数据目录，然后弹出 Atelier 窗口。
关闭 Atelier 后黑窗口会停下等你按任意键，然后自己关掉。

想换方式启动：

  scripts\start-p67-test.cmd --fresh
      丢掉上次测试的改动，重新从正式库复制一份数据

  scripts\start-p67-test.cmd --real
      直接使用正式数据目录（会执行迁移 006）

说明：本机 PowerShell 执行策略是 Restricted，双击 .ps1 会被系统拒绝，
所以这里用 .cmd。不需要修改任何系统安全设置。


二、数据安全（重要）
--------------------

默认启动使用的是独立测试目录：

  %LOCALAPPDATA%\Atelier\P6.7-test-data\atelier.db

首次启动时从正式库 %APPDATA%\atelier\atelier.db 复制一份过去。
你的正式库全程只被读取、不被写入。

已核对：本次准备工作结束后，正式库内容未变（本次不记录具体哈希）。
仍是 5 个迁移、没有新增的表。

如果你用 --real 直接跑正式库：
  - 首次启动会执行迁移 006（只新增一张明细表，不改动既有数据）
  - 迁移前会自动生成一份备份，和以前的迁移一致
  - 这一步不可逆（迁移是前向的），但不会删除或改写任何既有工时/任务/委托


三、请重点检查这 10 项
----------------------

1. 打开「日历」，月视图里每天是否显示实际绘画工时
2. 点击某一天，右侧是否出现「当天详情」
3. 详情里是否按任务分组，每个任务显示「当天」投入（不是累计总工时）
4. 当天涉及多个委托时，是否能看到不同委托
5. 没有关联任务的工时，是否单独显示在「未关联任务工时」区域
6. 点击任务旁的「定位任务」，是否跳到绘画任务页并高亮该任务
7. 点击「查看工时」，是否跳到工时记录页且日期已自动筛选好
8. 点击「查看委托」，是否跳到委托管理页并打开对应委托详情
9. 详情里「计划」和「实际」是否清楚分开（计划安排 vs 创作记录）
10. 原来的月/周视图、上一月/下一月/今天、未安排、排期建议是否都还正常


四、已知限制（不是 bug）
------------------------

1. P6.7 之前的老工时记录没有「活跃片段」数据。
   如果一笔老记录中间暂停过、又跨了午夜，它每天具体画了多久无法还原，
   会整笔算到开始那天。你当前库里这类记录是 0 条。

2. 合并过的工时记录、手工改过起止时间的记录，同样没有对应片段，
   按日精度会退化到「算在开始那天」，但不会丢秒、也不会重复计算。

3. 右侧详情面板在 80 宽的侧栏里内容较长时会滚动，这是预期行为。
   如果觉得太挤，请告诉我具体哪一块，我再压缩。

4. 从别的页面回到日历时，会保留你之前选中的日期。


五、如果出问题
--------------

把黑窗口里的文字截图发给我，特别是：
  - Electron 路径那几行
  - 「Electron exited with code ...」的退出码
  - 任何 [ERROR] 开头的行

如果窗口根本没弹出来，先确认：
  - D:\Atelier\atelier-electron-runtime\electron.exe 是否存在
  - out\main\index.js 是否存在（不存在就先跑 npx electron-vite build）
