画师工坊 使用教程与功能说明
版本：0.1.0
适用范围：Windows
数据模式：本地 SQLite，不上传云端

============================================================
一、安装与首次启动
============================================================

1. 安装包位置

最终安装包位于：

C:\Users\11415\AppData\Local\Atelier\release\画师工坊-Setup-0.1.0.exe

也可以按 Win + R，输入：

%LOCALAPPDATA%\Atelier\release

然后运行 画师工坊-Setup-0.1.0.exe。

2. 安装说明

- 默认安装到：%LOCALAPPDATA%\Programs\Atelier
- 安装时可以修改安装目录
- 按当前 Windows 用户安装，不需要管理员权限
- 会创建开始菜单和桌面快捷方式
- 安装包未做数字签名，Windows SmartScreen 可能提示
  确认来源后选择“更多信息 → 仍要运行”

3. 数据位置

用户数据固定保存在：

%APPDATA%\atelier\atelier.db

安装、升级、卸载都不会删除这个目录。

4. 首次启动

- 双击桌面 Atelier 图标，或从开始菜单启动
- 如果本机已有数据，会自动读取
- 如果打开是空数据，先确认数据目录是否为
  %APPDATA%\atelier，不要新建空数据库覆盖旧数据
  必要时使用设置页的“从备份恢复”

============================================================
二、主界面
============================================================

左侧导航：

概览
  今日/本周工时、当前计时、未分配工时、运行环境

委托管理
  客户、委托、任务

日历
  月/周视图、手动排期、排期建议

工时记录
  查看、归属、修正、合并、删除工时

设置
  自动监测、数据备份/恢复/导出

右侧为详情面板，顶部栏显示当前计时状态。

============================================================
三、基础数据：客户 → 委托 → 任务
============================================================

1. 新建客户

进入“委托管理” → “客户”页签：

- 点击新建客户
- 填写名称、联系方式、备注
- 保存

一个客户可以对应多个委托。

2. 新建委托

进入“委托管理” → “委托”页签：

- 点击“新建委托”
- 选择客户
- 填写委托名称、类型
- 设置优先级（1 最高，5 最低）
- 设置截止时间：
  无截止 / 仅日期 / 日期+时间（记录创建时区）
- 填写报价：
  未报价 / 免费 / 指定金额
- 保存

委托状态：

草稿 → 进行中 → 已完成
         ↘ 已取消

规则：

- 进行中的委托，在最后一个任务完成时可以自动完成
- 重新打开任务会让已完成的委托回到进行中
- 有未完成任务时，不能强行完成委托
- 付款状态由“报价”和“已收金额”自动计算
- 不允许超额收款

3. 新建任务

打开委托详情 → 任务区：

- 点击“新建任务”
- 填写任务标题
- 选择阶段：草稿 / 线稿 / 上色 / 完稿 / 其他
- 设置状态：待开始 / 进行中 / 已完成
- 填写预计工时（分钟）
- 可填写备注
- 保存

任务支持：

- 上移/下移排序
- 标记完成
- 归档/恢复
- 编辑
- 在任务行直接开始计时

任务区显示：

已完成数 / 任务总数 · 预计工时 · 实际工时

============================================================
四、日历与排期
============================================================

1. 手动排期

进入“日历”：

- 月视图/周视图切换
- 任务显示在计划日期上
- 委托截止日期单独显示，两者不混淆
- 右侧“未安排”面板列出未完成任务
- 点击任务可设置、修改或清除计划日期

计划日期只影响日历，不改变委托截止日期。

2. 排期建议

日历右侧切换到“排期建议”：

建议顺序：

- 逾期任务优先
- 截止更近优先
- 委托优先级
- 建议日期
- 预计工时
- 阶段和排序

每条建议显示：

- 紧急程度（逾期/本周/剩余天数/无截止）
- 建议开始日期
- 委托优先级
- 预计工时
- 委托截止日期

操作：

- 勾选建议
- 可修改建议日期
- 点击“采纳选中”后才会写入计划日期

注意：

- 这是建议，不是每日容量排班
- 多个任务可能建议同一天，这是正常的
- 已有计划日期的任务不会出现在建议中，也不会被覆盖
- 如果采纳前任务状态、预计工时、委托优先级或截止日期
  发生变化，会提示“建议依据已变化”，需要刷新后再采纳

============================================================
五、计时与自动监测
============================================================

1. 手动计时

在任务行点击“开始计时”。

顶部计时条会显示当前任务和累计时间，可：

- 暂停
- 继续
- 结束

同一时间只能有一个手动计时。

规则：

- 任务已完成/已归档，或委托不是草稿/进行中时，
  不能开始计时
- 程序崩溃或异常退出后，重新启动会把手动计时恢复为
  “暂停”，不会把停机时间算进去
- 连续计时达到 24 小时会自动暂停并提示

2. 自动监测（可选）

进入“设置” → “自动监测”：

- 默认关闭
- 开启后，只有受支持的绘画软件在前台时才记录
- 支持：
  Adobe Photoshop
  Clip Studio Paint
  PaintTool SAI
  Krita
  Blender
- 可设置空闲阈值，默认 3 分钟
- 可关闭“空闲检测”：
  数位笔输入有时不会被系统识别为活动
  如果自动记录经常提前停止，可以关闭空闲检测
  关闭后，思考时间也可能被计入，需要自己权衡

自动记录的特点：

- 只记录前台程序名和空闲时间
- 不读取窗口标题、文件路径、键盘内容，不截屏
- 自动产生的记录默认“未分配”
- 手动计时运行期间不会产生自动记录，避免重复计时

3. 自动工时归属

进入“工时记录”：

- 筛选“未分配”
- 找到自动记录
- 点击“归属”
- 选择任务
- 保存

============================================================
六、工时记录管理
============================================================

“工时记录”页面支持：

- 按日期范围查看
- 全部 / 未分配筛选
- 查看每日合计
- 编辑已完成记录：
  归属任务
  修改开始/结束时间（会重新计算时长）
  修改备注
- 删除记录（软删除，不计入统计）
- 合并记录：
  只能合并同一任务、同一来源
  自动记录还要求同一软件
  合并后保留溯源，旧记录不重复统计

注意：

- 正在计时的记录不能直接编辑，请先结束计时
- 工时统计以实际累计秒数为准，不按墙钟起止时间简单相减
- 修改系统时间不会产生负时长，偏差会被保留

============================================================
七、概览
============================================================

“概览”显示：

- 今日实际工时
- 本周实际工时与每日分布
- 当前计时状态
- 今日未分配工时
- 运行环境版本

适合每天开始工作前快速查看。

============================================================
八、数据备份、恢复与导出
============================================================

1. 备份

进入“设置”，点击“立即备份”：

- 生成完整数据库备份
- 保存到：

  %APPDATA%\atelier\backups\

- 文件名包含 UTC 时间
- 备份成功后显示完整路径
- 可点击“打开备份文件夹”

备份是完整 SQLite 数据库，可以用于恢复。

2. 恢复

点击“从备份恢复”：

1. 选择 .db 备份文件
2. 查看文件信息
3. 确认“当前数据将被替换”
4. 系统会先自动备份当前数据库
5. 恢复成功后应用自动重启

安全规则：

- 无效、损坏、来自更高版本的备份会被拒绝，
  当前数据不受影响
- 恢复过程中如果失败，会回滚到原数据库
- 有手动计时运行时必须先结束计时
- 正式数据库不会被无效备份覆盖

3. CSV 导出

点击“导出 CSV”：

- 选择导出目录
- 生成：
  Atelier-export-时间/
    clients.csv
    commissions.csv
    tasks.csv
    time_entries.csv
    manifest.json
    README.txt

特点：

- UTF-8 带 BOM，中文 Excel 直接打开
- 金额同时提供“分”和“元”
- 日期、本地时间、时区都有记录
- 工时只导出有效记录，不含软删除和已合并的重复记录
- 用户文本做了 Excel 公式注入防护，
  部分内容前可能出现单引号

重要：

CSV 导出不能用于恢复；恢复请使用数据库备份。

============================================================
九、升级与卸载
============================================================

1. 升级

直接运行新版本安装包，安装到原来的目录即可。

- 会保留 %APPDATA%\atelier
- 客户、委托、任务、计划日期、工时都会保留
- 升级前如数据库结构有变化，会自动生成迁移前备份

2. 卸载

从 Windows 设置或安装目录运行卸载程序。

- 删除程序文件
- 不会删除 %APPDATA%\atelier
- 数据库、备份和导出都会保留

如果确实要完全清除数据，请在确认已有外部备份后，
手动删除：

%APPDATA%\atelier

============================================================
十、推荐使用习惯
============================================================

每天：

1. 打开概览，看今日/本周工时
2. 打开日历，看今天和本周截止
3. 从任务行开始计时
4. 中途休息时暂停计时
5. 结束工作后结束计时
6. 到工时页处理未分配记录

每周：

1. 查看排期建议
2. 勾选并采纳下周任务
3. 检查逾期和本周截止的委托
4. 做一次“立即备份”

每月：

1. 导出一次 CSV，保存到网盘/移动硬盘
2. 把 %APPDATA%\atelier\backups 中的备份复制到其他磁盘
3. 归档已完成的旧任务

============================================================
十一、常见问题
============================================================

Q：安装时 Windows 提示不安全？
A：安装包没有数字签名，属于预期提示。
   确认来源后选择“更多信息 → 仍要运行”。

Q：安装后打开是空数据？
A：确认数据目录是否为 %APPDATA%\atelier。
   如果之前的数据在别处，使用“从备份恢复”选择备份，
   不要新建空数据库覆盖旧数据。

Q：自动监测不记录？
检查：
1. 设置里是否已开启自动监测
2. 对应绘画软件是否勾选
3. 软件是否在前台
4. 是否超过空闲阈值
5. 数位笔场景可尝试关闭“空闲检测”

Q：计时开始不了？
检查任务是否已完成或已归档，委托是否处于草稿/进行中，
以及是否已有另一个计时在运行。

Q：恢复失败？
检查备份是否完整、是否为 Atelier 数据库、是否来自更高版本。
失败时当前数据库会自动回滚，不要连续重复尝试。

Q：CSV 打不开或乱码？
使用 Excel 直接打开导出的 CSV；文件已带 UTF-8 BOM。
不要使用不支持 UTF-8 的旧工具。

============================================================
十二、当前限制
============================================================

- 仅支持 Windows
- 数据只在本机，不提供云同步、多设备同步
- 任务阶段固定为五类，不支持每委托自定义流程
- 任务没有独立截止日期，统一继承委托截止
- 排期建议不使用每日容量、工作日、任务依赖，也不自动排期
- 自动监测仅作为参考，不保证等同真实绘画时间
- CSV 不能反向导入
- 安装包未签名，可能出现 SmartScreen 提示
- 不提供自动更新，升级需要手动运行新安装包

============================================================
十三、最重要的两条
============================================================

1. 每天结束前处理一次“未分配工时”，
   否则统计会不完整。

2. 定期备份，并把备份复制到另一块磁盘；
   卸载不删数据，但磁盘损坏无法靠本机备份恢复。
